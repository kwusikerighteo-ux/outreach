# Outreach Analytics

Email marketing dashboard for the **CRM Data** Google Sheet.

- **Desktop dashboard:** `/` (index.html)
- **Mobile app (installable):** `/mobile-app/`

## First use

1. Open the site and go to **Settings**.
2. Paste the spreadsheet link and the Google API key, then tap **Test & save**.

The sheet ID and API key are not stored in this repository. They are saved only in the browser of each device you connect.

## Install on Android

Open `https://<your-username>.github.io/<repo-name>/mobile-app/` in Chrome, then tap **Install** in Settings (or ⋮ → **Install app**).
