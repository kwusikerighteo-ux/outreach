# Outreach Analytics

Email marketing dashboard and Unibox, powered by an Outreach Hub script in each client's CRM sheet.

- **Desktop dashboard:** `/` (index.html)
- **Mobile app (installable):** `/mobile-app/`

Clients connect by opening their personal link (Outreach menu → Show links in their sheet). Nothing to type: the link connects the app on that device.

No sheet IDs, API keys or passwords are stored in this repository.
